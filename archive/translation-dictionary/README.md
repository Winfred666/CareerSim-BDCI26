# Archived dictionary workflow

The live solution uses O/N/S/HW/R questionnaires. This directory preserves the
last live dictionary, its retrieval helpers/tests and the former benchmark skill.
Legacy benchmark drivers and reports are in
`career_sim_runner/translation_benchmark/archive/`.

Historical SQLite and run directories remain untouched. The selected historical
full-pool baseline is `20260923T182215Z-career-sim-translation-v1` (217 rows,
68.51% weighted cosine); new reports reuse its original matching-event answers.
Archive contents are not installed into the solution or fed to questionnaire agents.
